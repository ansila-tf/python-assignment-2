Python Fundamentals – Assignment 2

Data Structures: List, Dictionary, Set & Conditional Statements

About the Assignment

This assignment focuses on understanding and implementing basic Python concepts, including Lists, Dictionaries, Sets, Operators, and Conditional Statements.

Topics Covered

1. Lists

* List creation
* Append and insert operations
* Remove and pop operations
* Extend and sort operations
* Finding maximum, minimum, and sum
* Accessing list elements

2. Dictionaries

* Dictionary creation
* Accessing dictionary elements
* Adding new key-value pairs
* Updating values
* Using keys(), values(), and items() methods

3. Sets

* Set creation
* Understanding duplicate elements
* Set indexing and modification
* Union operation
* Intersection operation

4. Operators and Conditional Statements

* User input
* Comparison operators
* if, elif, and else statements
* Performance category program
* Input validation

Technologies Used

* Python 3
* Visual Studio Code
